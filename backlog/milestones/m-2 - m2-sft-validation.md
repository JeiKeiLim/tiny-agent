## Description

Build the Kestrel SFT stack and run 50M short-context SFT validation. Scope includes chat template, SFTDataset, data prep for the locked 50k mixture, public tool normalizer, local tool generator, optional internal LLM generator, SFT trainer, SFT eval, and 5k/20k/50k data-scaling runs. 150M is config-supported but not the first execution target.
