## Description

Build the pretraining stack (corpus builder, pretrain dataset, shared trainer, pretrain loop, generate) and validate it with a ~50M-token run on Kestrel-50M (loss down + coherent text). Full ~1B-token run is a separate follow-up. 50M-first; 150M is a later manual pass.
