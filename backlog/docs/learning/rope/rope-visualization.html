RoPE core mechanism, distance, periodicity, and training

This version leads with the general RoPE mechanism instead of a specific example. It explains how q/k rotation creates relative-position-aware attention scores, what happens at 360°, why real multi-frequency RoPE does not simply reset, and how training interacts with the fixed rotation.

Core ideas

Attention score
One query vector and one key vector produce one scalar: q·k.
RoPE
Rotates each token’s q and k by an amount determined by that token’s position.
Relative position
The rotated dot product depends mainly on position difference, not absolute position.
Single frequency
If only one rotation frequency exists, the signal is periodic and can repeat after 360°.
Multi-frequency RoPE
Real RoPE uses many frequencies, so the full pattern does not simply reset at one 360° event.
Training
Gradients flow through RoPE, but the rotation frequencies are fixed; q/k projections are learned.

2. Your 360° question: one frequency does repeat

If RoPE used only one frequency, then yes: when the rotation angle changes by 360° (2π radians), that frequency’s score repeats. The period in tokens is:

3. Real RoPE uses many frequencies, so the full signal does not simply reset

A real RoPE head rotates many dimension pairs at different frequencies. Think of it as many clocks spinning at different speeds. One clock may complete 360°, but the others generally will not.

The thin lines are individual frequency components. The thick green line is their combined RoPE-like score. The combined signal is much less likely to exactly repeat at a single 360° event.

5. Training: what changes and what stays fixed?

RoPE is differentiable, so backprop flows through it. But the rotation table is not a learned parameter.

Forward

Token embeddings
→
q_proj / k_proj / v_proj
→
RoPE rotation, fixed frequencies
→
q·k scores
→
softmax + value mixing
→
loss

Backward

loss
→
attention gradients
→
gradients wrt rotated q/k
→
through fixed RoPE math
→
update q/k/v projections + embeddings

The model learns q/k vectors that are useful when passed through the fixed positional rotation.
